# Tales of Rebirth 한국어 패치

PSP **Tales of Rebirth (일본판, ULJS00132)** 팬 한국어 번역 패치입니다.

본편 대사부터 스킷, 메뉴, 배틀 텍스트, 도감, 줄거리북, 마을 진입 타이틀 이미지까지
게임에 나오는 텍스트를 한국어로 옮겼습니다.

> 이 저장소에는 **게임 데이터가 들어 있지 않습니다.**
> 본인이 소유한 게임에서 직접 추출한 ISO 에만 적용할 수 있습니다.

---

## 다운로드

[**Releases**](../../releases) 에서 최신 패치를 받으세요.

## 적용 방법

1. 받은 압축 파일을 아무 폴더에나 풉니다.
2. 원본 ISO 를 `apply_patch.bat` 위로 **끌어다 놓습니다.**
   (또는 원본 ISO 를 같은 폴더에 복사한 뒤 `apply_patch.bat` 을 실행)
3. 같은 폴더에 한글판 ISO 가 만들어집니다. 원본 ISO 는 그대로 남습니다.

적용에 실패한다면 대개 아래 둘 중 하나입니다.

- **이미 패치된 ISO** 에 다시 적용한 경우 → 원본 ISO 로 다시 시도하세요.
- **CSO** 로 압축된 파일인 경우 → ISO 로 되돌린 뒤 적용하세요.
  (적용이 끝난 뒤 다시 CSO 로 압축하는 것은 괜찮습니다.)

## 패치 후 주의사항

- **세이브스테이트로 이어하지 마세요.** 예전 데이터가 메모리에 남아 일부가 일본어로
  보입니다. 게임을 완전히 새로 실행하면 됩니다. 세이브 파일 자체는 그대로 쓸 수 있습니다.
- 치트(CWCheat)를 켠 상태에서는 배경이 깨지는 등 패치와 무관한 문제가 생길 수 있습니다.

## 알려진 제약

원본 엔진 구조상 고칠 수 없거나, 고치면 오히려 불안정해지는 부분들입니다.
버그가 아니라 알려진 한계입니다.

- 일부 칭호·설명문에서 색이 들어간 단어 뒤에 여백이 보입니다.
- 기술 습득 안내에서 기술명 뒤에 여백이 보입니다.
- 장비 분류 배지처럼 아주 짧은 라벨은 한 글자로 줄였습니다. (예: 지팡이 → 장)
- 가나 입력이 필요한 퀴즈는 한글 자판이 없어 정답을 칠 수 없으므로,
  입력창이 열릴 때 **정답이 미리 입력되어 있습니다.** 그대로 결정만 누르면 넘어갑니다.
